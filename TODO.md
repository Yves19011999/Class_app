# Refonte Class App — résultats

## Shell et navigation

- [ ] Le rail latéral est unique, lisible et persistant sur tablette/DeX/desktop.
- [ ] Le téléphone utilise un tiroir modal sans barre basse concurrente.
- [ ] Le contenu ne se retrouve pas sous le profil, la recherche ou le menu.
- [ ] Les états actif, survol, focus et désactivé sont visuellement distincts.

## Dashboard

- [ ] Les KPI sont compacts, lisibles et cliquables.
- [ ] Les cartes ont une hiérarchie stable et un état vide propre.
- [ ] Les actions rapides sont regroupées et réellement accessibles.
- [ ] Le dashboard reste utilisable en portrait téléphone, paysage tablette et DeX.

## Composants

- [ ] Les boutons, champs, badges, cartes, sheets et toasts partagent un même langage visuel.
- [ ] Les contrastes et zones tactiles restent accessibles.
- [ ] Les animations sont courtes et non bloquantes.

## Livraison

- [ ] Compiler l’APK release avec un versionCode supérieur.
- [ ] Vérifier la signature et le package Android.
- [ ] Publier la refonte sur la branche GitHub de travail.
